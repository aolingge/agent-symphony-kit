# Market Notes

## Thesis

Coding-agent orchestration is becoming a real category, but many tools start as full platforms. Agent Symphony Kit targets the smaller wedge: local-first task state, verification gates, and handoff records for developers who already use coding-agent CLIs.

## Differentiation

- Local-first: state stays in the repo.
- Markdown/JSON-native: easy to inspect, diff, commit, or archive.
- Agent-neutral: works around any CLI because it starts with workflow contracts and gate commands.
- Safety-first: no automatic publish, push, merge, delete, spend, DNS, or credential persistence.
- Zero runtime dependencies.

## Adjacent Tools

- OpenAI Symphony: issue-tracker-driven orchestrator and spec.
- Composio Agent Orchestrator: fuller multi-agent platform.
- Stoneforge: dashboard and event-sourced runtime for agent fleets.
- CrewAI: Python framework for multi-agent applications.
- OpenClaw: local personal automation agent OS.

Agent Symphony Kit should not compete as a full platform. It should be the installable local workflow layer users can adopt before choosing a heavier orchestrator.
